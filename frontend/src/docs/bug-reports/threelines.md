# Three lines do nothing when screen resized

## Description
When the screen is resized to 1/2 its size, the three lines representing the menu do nothing when clicked

## Steps to Reproduce
1. Shrink screen to 1/2
2. Click on three lines in top right corner
3. Nothing happens

## Expected Behavior
Menu is displayed(Schedule, 4yr plan, profile, light or dark mode)

## Actual Behavior
No response

## Notes
Icon may not have any code to initiate action when clicked
