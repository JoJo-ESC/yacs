# Search results are misaligned when displayed on the 4 year, Schedule, and Profile pages

## Description
When you use the search bar on the 4 year, Schedule, and Profile pages the results start at the very top of the page, a portion of it thus blocked by the navbar.

## Steps to Reproduce
1. Visit either the 4-year planner, Schedule, or profile pages
2. Type a character into the search to receive results
3. Results start above the nav bar

## Expected Behavior
Results drop down below search bar, not above

## Actual Behavior
Results start above the search bar, some blocked by navbar

## Notes
UI error
