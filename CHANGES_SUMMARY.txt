YACS - Maksymilian's Changes Summary
Updated: October 22, 2026

Scope: Changes authored by Maksymilian (Zumaks) in the current branch history,
through commit c23a492. Please note that some of the implementations were
later adapted or replaced by upstream changes during the October 20 merge.

1. Error and not-found pages
Added a 404 page for invalid URLs and an error boundary for application errors,
then refined routing, error handling, and supporting tests.
Commits: 9bc9226, 215773f

2. Reusable loading spinner
Created a shared spinner component for displaying loading feedback.
Commit: 3bdc8a4

3. Course loading feedback
Displayed a spinner while courses load and added skeleton placeholders for
course cards, with frontend tests for both loading states.
Commits: 35cfaa6, 778097c

4. Login loading state
Added a login page with loading feedback during submission and supporting
navigation, routing, and frontend tests.
Commit: cb8e619

5. Schedule calendar export
Added ICS export so users can import their course schedule into calendar apps,
with export helpers and automated tests.
Commit: 3d609e3

6. Schedule PDF export
Added a printable schedule view that users can save as a PDF, with tests for
the export behavior.
Commit: b2fc33a

7. Schedule image export
Added PNG export for saving the schedule as an image, with automated tests.
Commit: cb577d5

8. Copy schedule as text
Added a clipboard option for copying a readable text version of the schedule,
with supporting export tests.
Commit: 24e26a0

9. Finals page
Created the frontend finals page and route, including supporting structure for
future backend integration and a route test.
Commit: ba37c6d

10. Finals exports
Added calendar (ICS), PDF, PNG, and clipboard text exports for finals schedules,
with shared export utilities and tests.
Commits: 72792b8, 5849a98, 8b39d53, cd04d00

11. Semester selection
Added a semester dropdown, shared selection state, semester-based course
filtering, and localStorage persistence for the last selected semester.
Commits: 3e72ece, caf674f, ef8805e, 5d89c01

12. Backend semesters endpoint
Added /api/semesters with a router and service that read configured semesters
or discover them from scraper data filenames, plus semester service tests.
Commit: 2f237f3

13. Professor directory
Added a professor directory built from the selected semester's catalog,
including navigation, routing, and frontend tests.
Commit: ce77398

14. Professor details and courses

with supporting catalog utilities and tests.
Commits: 35ef1a4, ccf5041

professor detail page, with frontend tests.
